# Historical Design Notes: 5V Through-Hole Power Supply

## Overview
This document preserves the initial project notes for the through-hole 5V power supply design created using KiCad. It includes the schematic diagram, PCB layout, Bill of Materials, and manufacturing outputs.

## Tools Used
- KiCad (v7 or later; files generated in KiCad 9)

## Design Previews
Vector previews generated from the KiCad design files:
- Schematic: [schematic.svg](schematic.svg)
- PCB Layout: [pcb_layout.svg](pcb_layout.svg)

## Directory Structure
- `HARDWARE/`: KiCad schematic (`.kicad_sch`) and PCB layout (`.kicad_pcb`)
- `BOM/`: Bill of Materials (`bom.csv`)
- `GERBER/`: Gerber outputs (`.gbr` and `.gbrjob`)

## Opening the Project
1. Install KiCad (v7 or later; v9 recommended to match file version).
2. Open the schematic file in `HARDWARE/Kicad-Hardware-Design.kicad_sch` or layout in `HARDWARE/Kicad-Hardware-Design.kicad_pcb`.

## Project Outputs
- Schematic design
- Single-sided PCB layout (Bottom copper `B.Cu`)
- Bill of Materials (BOM)
- Bottom copper Gerber and job file
